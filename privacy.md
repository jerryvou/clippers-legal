# Privacy Policy

**Clippers Studio** — Last updated: October 11, 2026

Clippers Studio is a personal, single-user tool used by its owner to prepare and publish the
owner's own videos to the owner's own TikTok accounts.

## Data processed

- **TikTok account data**: basic profile information and authorization tokens provided by
  TikTok's official APIs after the owner authorizes the Application. Used only to publish the
  owner's own content.
- **Video files**: videos prepared by the owner locally; uploaded to TikTok via the Content
  Posting API only on the owner's request.
- **Local processing**: all preparation (downloads, editing, rendering) happens on the owner's
  own computer. No data is transmitted anywhere except TikTok's official APIs.

## Data not collected

- No third-party data is collected.
- No analytics, tracking pixels, or advertising services are used.
- This website is static and does not set cookies.

## Sharing

No data is sold or shared with any third party. Videos and metadata reside only on the owner's
computer and on TikTok, subject to TikTok's own policies.
